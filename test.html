自訂捲軸樣式示範

往下捲動看看右邊捲軸的樣子，跟瀏覽器預設的粗黑捲軸做對比

這是第一段內容

這裡隨便打一些文字撐高頁面，方便你看到捲軸的效果。捲軸樣式主要靠 ::-webkit-scrollbar 這組偽元素選擇器控制，這是 Webkit 核心瀏覽器（Chrome、Edge、Safari）專屬的語法。

Firefox 用的是完全不同的語法：scrollbar-width 跟 scrollbar-color，兩組語法要一起寫才能兼顧不同瀏覽器。

第二段：捲軸寬度

原生捲軸通常是 15~17px 寬，這裡示範改成 10px，看起來會比較細緻、不那麼佔畫面空間。

第三段：滑塊圓角與邊框

border-radius 讓滑塊變成膠囊形狀，border 則是用「跟背景同色的邊框」製造出滑塊比軌道還細一圈的視覺效果，這是很常見的技巧。

第四段：hover 變色

把滑鼠移到右邊捲軸的滑塊上，顏色會從灰色變成藍色，這是 ::-webkit-scrollbar-thumb:hover 做出來的互動效果。

第五段：繼續撐高頁面

多加幾段文字，確保頁面夠長，能明顯看到捲軸拖曳的效果。你可以試著把上面 CSS 裡的數值改一改，例如把 width 改成 20px，或把顏色換掉，看看差異。

也可以試著把整段 ::-webkit-scrollbar 相關的 CSS 刪掉，重新整理頁面，比較一下瀏覽器預設捲軸長什麼樣子。

第六段：結尾

捲到底了，這就是自訂捲軸樣式的完整示範。
